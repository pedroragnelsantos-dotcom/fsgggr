# Biblioteca Digital Acessível

Projeto educativo desenvolvido em **HTML5** e **CSS3** com o objetivo de apresentar materiais de leitura e estudo de forma simples, organizada e acessível.

## Funcionalidades e Estrutura

- **Cabeçalho e Menu de Navegação:** Links diretos para *Início*, *Livros*, *Categorias* e *Sobre o projeto*.
- **Seção de Categorias:** Organização visual das áreas de conhecimento (*Tecnologia*, *Literatura*, *Ciências*, *Matemática*, *História* e *Desenvolvimento pessoal*) com ícones e textos claros.
- **Catálogo de Livros:** 6 cards contendo capa ilustrativa, título, autor, categoria, descrição breve e botão **Ver detalhes**.
- **Layout Responsivo:** Adaptação para computadores, tablets e celulares utilizando `display: grid`, `display: flex` e regras `@media`.

## Boas Práticas de Acessibilidade Aplicadas

1. **Hierarquia semântica de títulos:** Uso estruturado de `<h1>`, `<h2>` e `<h3>`.
2. **Textos curtos e objetivos:** Descrições diretas e fáceis de compreender.
3. **Tipografia legível e espaçamento:** Fonte sem serifa com boa altura de linha (`line-height: 1.6`) e respiro entre os blocos.
4. **Alto contraste:** Combinação de cores entre texto e fundo seguindo padrões de legibilidade.
5. **Descrições alternativas:** Todas as imagens possuem o atributo `alt` descritivo.
6. **Navegação previsível e sem distrações:** Botões com rótulos claros, foco visível para teclado e ausência de animações desnecessárias.

## Como visualizar o projeto

1. Abra o arquivo `index.html` em qualquer navegador web.
2. Para publicar no GitHub Pages, acesse **Settings > Pages**, selecione a branch `main` e a pasta `/ (root)` e clique em **Save**.
